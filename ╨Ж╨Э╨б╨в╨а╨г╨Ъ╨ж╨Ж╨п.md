# Карта загроз — як запустити

## Файли
| Файл | Що це |
|---|---|
| `index.html` | Публічна карта, яку бачать усі відвідувачі |
| `admin.html` | Адмін-панель: ставиш тривоги й цілі, пишеш у стрічку |
| `map.js`, `style.css` | Код і стилі (потрібні обом сторінкам) |
| `config.js` | Сюди вставляєш ключі Supabase |
| `setup.sql` | Створює базу даних у Supabase |

Без ключів сайт працює в **демо-режимі**: усе зберігається лише у твоєму браузері. Так зручно спробувати: відкрий `admin.html` і `index.html` у двох вкладках.

## 1. База даних (Supabase, безкоштовно)
1. Зайди на supabase.com → **New project** (або використай наявний проєкт).
2. **SQL Editor → New query** → встав увесь `setup.sql` → **Run**.
3. **Authentication → Users → Add user → Create new user**: свій email і пароль, галочка **Auto Confirm User**.
4. У SQL Editor виконай (зі своїм email):
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'ТВІЙ_EMAIL@gmail.com';
   ```
5. **Authentication → Sign In / Providers** → вимкни **Allow new users to sign up**, щоб ніхто сторонній не міг зареєструватися. Права адміна в них однаково не буде, але так надійніше.

## 2. Ключі
**Project Settings → API** (або **Data API / API Keys**):
- **Project URL** → у `config.js` у поле `SUPABASE_URL`
- **anon public** (або **publishable**) ключ → у поле `SUPABASE_ANON_KEY`

Цей ключ можна показувати публічно: змінювати дані дозволено лише адмінам, це забезпечують правила в базі.
**Ніколи** не вставляй ключ `service_role` / `secret`.

Тут же можна змінити назву сайту (`SITE_NAME`).

## 3. Хостинг (GitHub Pages)
1. Створи репозиторій і завантаж туди всі файли з цієї папки.
2. **Settings → Pages → Deploy from branch → main / root**.
3. Сайт: `https://ІМʼЯ.github.io/РЕПО/`, адмінка: `…/admin.html`.

## Як користуватися адмінкою
- **Тривога**: обери 🔴 Тривога / 🟡 Загроза / 🟢 Відбій і область цілком або окремий район, потім клікай по карті. Клік по назві області справа перемикає: тривога → загроза → відбій.
- **Цілі**: обери тип і достовірність, потім клікни по карті. Щоб задати курс, потягни мишкою. На публічному сайті стрілка курсу видна лише за середньої або високої достовірності.
- **Вибір**: клікни ціль, щоб змінити кількість, тип, курс чи примітку. Ціль можна перетягнути, і тоді лишиться слід маршруту. Кнопка «Актуально» оновлює час цілі.
- **Стрічка**: повідомлення бачать усі. Можна ввімкнути автоматичні повідомлення про тривоги й відбої.
- Цілі, які давно не оновлювались, можна прибирати автоматично (налаштування). Для цього адмінка має бути відкрита.

## Межі районів
Сайт сам підвантажує справжні межі 136 районів (за реформою 2020 року) з відкритого набору даних
[ukrainian_geodata](https://github.com/slawomirmatuszak/ukrainian_geodata) (ліцензія CC BY 4.0, підпис уже є на сайті).

Щоб не залежати від чужого сервера, можна покласти файли до себе:
1. Скачай `rayony.geojson` і `regiony.geojson` з того репозиторію (кнопка **Download raw file**).
2. Створи на своєму сайті папку `geo` і поклади їх туди. Сайт спершу шукає їх там.

Якщо файли не завантажаться, сайт покаже запасну схематичну карту.

## Важливо
Межі на запасній схематичній карті приблизні. Сайт не замінює офіційні сигнали тривоги, і цей напис уже є на сторінці.

## Автоматичні тривоги з alerts.in.ua
Функція в Supabase щохвилини забирає активні повітряні тривоги з alerts.in.ua і записує їх у базу.
На сайті такі тривоги позначені «авто», ручні з адмінки працюють як і раніше.

1. **Ключ alerts.in.ua.** Заповни форму запиту на devs.alerts.in.ua і дочекайся токена.
2. **Секрети.** Supabase → **Edge Functions → Secrets** → додай:
   - `ALERTS_IN_UA_TOKEN` = токен з alerts.in.ua
   - `CRON_SECRET` = будь-який довгий випадковий рядок (придумай сам)
3. **Функція.** **Edge Functions → Deploy a new function → Via Editor**, назва `sync-alerts`.
   Встав увесь код з `supabase/functions/sync-alerts/index.ts` → **Deploy**.
   Потім у налаштуваннях функції **вимкни «Verify JWT»** (захист робить `CRON_SECRET`).
4. **Розклад.** У `setup-auto-alerts.sql` заміни `СЕКРЕТ` на свій `CRON_SECRET` і виконай файл у SQL Editor.
5. **Перевірка** через хвилину: `select status_code, content from net._http_response order by created desc limit 5;`
   Має бути `200` і `"ok":true`. Якщо в `unmatched` є назви, надішли їх, і я допишу відповідності.
